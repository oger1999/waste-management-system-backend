# Description
Backend REST API for the Waste Management System, built with Spring Boot, Spring Data JPA and Mysql. It manages residents, collectors, trucks, waste types, pickups and waste loads.
# Requirements
- Java 17 
- Maven 3.8
- mysql
- Postman
# Steps to run the API
1. Clone the repository:
   `git clone https://github.com/oger1999/waste-management-system-backend.git`
2. Go into the project folder:
   `cd waste-management-system-backend`
3. Create the mysql database:
   `CREATE DATABASE waste_management_system;`
